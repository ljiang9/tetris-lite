# tetris-lite

迷你俄罗斯方块引擎：7 种四联方块、旋转（含简单踢墙）、重力、消行计分，
外加一个启发式自动游玩的无头演示。纯标准库，无第三方依赖。

## 玩法 / 用法

```bash
python -m tetris_lite --auto --pieces 50 --seed 42
```

- `--auto`：自动游玩 N 个方块（默认 50），结束后打印场地、消除行数与得分
- `--seed`：固定随机种子，方块序列可复现
- 无参数运行时只显示帮助——本项目**没有实时键盘操作模式**

## 设计取舍

- 旋转用"矩阵旋转 + 归一化"实现，预计算去重后的旋转状态
  （O 1 种、I/S/Z 2 种、T/J/L 4 种），踢墙只试左右各 1~2 格的简化版，
  不是完整 SRS。
- 计分：1/2/3/4 行 = 100/300/500/800，无等级加速（无头演示用不上）。
- 自动 AI 是经典 Dellacherie 式启发式（高度/空洞/凹凸/消行加权），
  能玩但不强：seed 42 跑 50 块消 18 行、1800 分。
- 发牌用 7-bag 洗牌，方块序列公平。

## 验证记录（真实执行）

- `py_compile` 通过
- 旋转状态数断言（O=1、I/S/Z=2、T/J/L=4），旋转 4 次回到原状
- 单行消除 +100、四行 800；满行确实被移除
- 顶部 3 行填满后出生碰撞 → game over
- 同种子 14 连抽序列一致，且恰为两套 7-bag
- I 在左边缘旋转不穿墙（踢墙生效）
- 重力 `step()` 下落一格
- `--auto --pieces 50 --seed 42`：50 块放完，18 行，1800 分，两次运行一致

## 已知局限

- **没有实时输入**：不能用键盘玩，只有 `--auto` 演示和可 import 的引擎
- AI 是简单启发式，非最优策略；高堆时可能失误堆满
- 简化踢墙，贴墙旋转偶尔失败（返回 False，不穿墙）
- 无存档、无最高分记录、无等级/速度曲线
